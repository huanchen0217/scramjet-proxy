Scramjet Proxy

Browse the web freely. No censorship, no restrictions.

No Wisp server configured. The proxy will not work without one.

How to configure

Edit config.js and set WISP_URL to your Wisp WebSocket server address (e.g. wss://your-server.com/wisp/).

You can run a Wisp server using wisp-js or deploy the full Node.js server from this repo.
